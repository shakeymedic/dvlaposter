# Fitness to drive: A3 poster

Two A3 posters for the Emergency Department at University Hospitals Birmingham, in one page (`index.html`): a **simple** poster (main diagnosis types, Group 1 and Group 2, QR code) and a **detailed** poster (main conditions with the action for each group). Switch between them with the tabs (or link to `#simple` / `#detailed`), then use **Print this poster** or **Print both** (A3, background graphics on, no margins).

- **Content:** a summary of the DVLA guide *Assessing fitness to drive: a guide for medical professionals* (GOV.UK version updated 7 November 2025). It deliberately leaves out how long patients must stop driving, because those periods change; the QR codes link to the current guidance.
- **Logo:** put the official Trust logo file in this folder as `uhb-logo.png`. Until it exists, the poster shows the Trust name as text instead.
- **Review date:** printed on the poster (April 2027). Before reprinting, check the GOV.UK guide's "Last updated" date and change notes, and update the poster and its review date.
